Грамматическая памятка для студентов: глаголы и маркеры времени

🔹 I Спряжение (ЧИТАТЬ / ДЕЛАТЬ)

  • Я чита́-ю / де́ла-ю
  • Ты чита́-ешь / де́ла-ешь
  • Он / Она чита́-ет / де́ла-ет
  • Мы чита́-ем / де́ла-ем
  • Вы чита́-ете / де́ла-ете
  • Они чита́-ют / де́ла-ют

Сюда же: завтракать, обедать, гулять, отдыхать.

🔹 II Спряжение (ГОВОРИТЬ / УЧИТЬ)

  • Я говор-ю́ / уч-у́ (сп-лю́)
  • Ты говор-и́шь / у́ч-ишь (сп-и́шь)
  • Он / Она говор-и́т / у́ч-ит (сп-и́т)
  • Мы говор-и́м / у́ч-им (сп-и́м)
  • Вы говор-и́те / у́ч-ите (сп-и́те)
  • Они говор-я́т / у́ч-ат (сп-я́т)

Чередования в 1-м лице: готовить ➔ я готовлю.

⏰ Когда? (Маркеры времени)

у́тром (in the morning)
днём (in the afternoon)
ве́чером (in the evening)
но́чью (at night)

Сначала (first / d'abord) ➔ Потом (then / ensuite)

📊 Как часто? (Частотность)

всегда́ (100%) — always / toujours
обы́чно (80%) — usually / d'habitude
ча́сто (60%) — often / souvent
иногда́ (30%) — sometimes / parfois
ре́дко (10%) — rarely / rarement
никогда́ не... (0%) — never / jamais
